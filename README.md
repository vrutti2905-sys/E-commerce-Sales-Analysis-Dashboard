# E-commerce Sales Analysis Dashboard | Microsoft Excel

## Project Overview
This project analyzes e-commerce sales data using Microsoft Excel to understand sales performance, profitability, product categories, and customer purchasing patterns. The dashboard presents key business metrics through interactive charts, a map, and filters.

## Key Performance Indicators (KPIs)
- **Total Sales:** $2,297,200.86
- **Total Profit:** $286,397.02
- **Quantity Sold:** 37,873
- **Number of Orders:** 9,994
- **Profit Margin:** 12.47%

## Dashboard Features
- **Sales and Profit Analysis:** Compares monthly sales and profit.
- **Category-Wise Profit:** Analyzes profit across Furniture, Office Supplies, and Technology.
- **Category-Wise Sales Share:** Shows each category's contribution to total sales.
- **Sales by State:** Displays geographical sales distribution across the United States.
- **Top 5 Subcategories:** Highlights Phones, Chairs, Storage, Tables, and Binders.
- **Year-over-Year Growth:** Displays changes in key business metrics.
- **Interactive Filters:** Explore data by year, region, and customer segment.

## Tools and Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Excel Charts and Map Visualization
- Slicers and Interactive Filters
- Data Analysis and Dashboard Design

## Key Insights
- Technology contributes the largest share of sales at 36.40%.
- Technology has the highest profit among the three categories.
- Phones and Chairs are the top two subcategories by sales.
- The dashboard helps compare monthly performance and explore sales across states, regions, and customer segments.

## Project Objective
The objective is to transform sales data into meaningful insights using Excel and support better business decisions through clear and interactive visualizations.

## Conclusion
This project demonstrates practical skills in Excel data analysis, visualization, KPI reporting, and interactive dashboard development.
